# 通用数据看板构建器（多数据源 / 丰富组件 / 栅格布局）

借鉴 WPS 多维表格仪表盘、飞书多维表格仪表盘、腾讯云 Dashboard 等主流看板的**组件库与模块布局**，支持多数据源、数据源模板自定义、8 类可视化组件、12 列栅格自由布局。看板随底层数据与配置实时联动更新。

## 快速开始

双击 `index.html` 即可用浏览器打开，无需安装任何环境。内置示例看板，也可「重置」后从零搭建。

## 组件库（8 类，参考主流看板）

| 组件 | 说明 | 关键配置 |
|------|------|----------|
| KPI 指标卡组 | 顶部汇总指标卡 | 多指标：名称/字段/聚合/比率/百分比/颜色/说明 |
| 统计数字卡 | 单个大数字 + 说明 | 标签/字段/聚合/后缀/颜色 |
| 仪表盘 / 进度环 | 环形仪表盘 | 标签/字段或比率/量程上限/后缀/颜色 |
| 图表 | ECharts 渲染 | 柱状/条形/折线/面积/饼/环形/漏斗/雷达 |
| 卡片组 | 每行一张卡 | 标题/标签/数值字段/比率进度条 |
| 排行榜 | 按字段排序 Top N | 排序字段/升降序/条数 |
| 明细表 | 数据表格 | 展示字段列 |
| 文本模块 | 标题/说明文字 | 支持 HTML 标签 |

## 核心能力

- **多数据源**：一个看板绑定多个数据源，各模块独立选择数据源
- **数据源模板自定义**：自由定义字段结构（增删字段、改类型），字段以 ID 存储，改名不丢数据
- **数据导入**：上传 Excel/CSV、粘贴 CSV/TSV、手动增删行编辑
- **栅格自由布局**：12 列栅格，模块可配宽度（全宽 / 2/3 / 1/2 / 1/3 / 1/4），支持上移/下移排序
- **模块级详细配置**：每个组件独立的动态配置面板
- **持久化**：数据与配置自动保存到浏览器本地（localStorage）

## 数据格式

各数据源字段由模板自定义。导入表格首行为表头，自动匹配模板字段，未匹配表头自动新建字段。

## 技术栈

原生 HTML + CSS + JavaScript（单文件）；图表用 ECharts 5；Excel 解析用 SheetJS。两者均通过 CDN 加载（需联网，离线时图表降级为提示、Excel 可用 CSV 粘贴导入）。
